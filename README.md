# Sakila Database Analysis

DVD Rental Data Analysis for Database Management Course

## Project Overview
Analysis of Sakila DVD rental database for insights into rental patterns, customer behavior, and revenue.

## Tasks
- [ ] Task 0: Data migration (SQLite → DuckDB)
- [ ] Task 1: Exploratory Data Analysis
  - [ ] 1a: Movies longer than 180 minutes
  - [ ] 1b: Movies with "love" in title
  - [ ] 1c: Descriptive statistics
  - [ ] 1d: Top 10 most expensive movies per day
  - [ ] 1e: Top 10 actors by movie count
  - [ ] 1f: Custom analysis questions
- [ ] Task 2: Data Visualizations
  - [ ] 2a: Top 5 customers by spend
  - [ ] 2b: Revenue per film category
- [ ] Task 3 (VG): BI Dashboard
- [ ] Task 4: Video presentation

## Stack
- Python, DuckDB, Pandas, Matplotlib, Jupyter
